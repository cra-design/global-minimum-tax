Who must file a return or notification

In general, at least one member of a qualifying multinational enterprise (MNE) group must file for a particular fiscal year when the group has a constituent entity located in Canada for the fiscal year.

On this page

  • Returns and notification related to the tax
  • Who must file a GloBE Information Return (GIR) or a GIR notification
  • Who must file a global minimum tax return

Returns and notification related to the tax

A member of a qualifying MNE group must file one or more of the following returns or notification:

  • GloBE Information Return (GIR)
  • Global minimum tax return
  • GIR Notification

A constituent entity or person may be appointed to file on behalf of all constituent entities or persons that must file with the CRA.

When an MNE group is not filing a GIR in a jusrisdiction other than Canada

If the MNE group appoints a designated filing entity located in Canada:

  • The designated filing entity is required to file the GIR
  • No GIR notification needs to be filed

If no designated filing entity is appointed and the ultimate parent entity of the MNE group is located in Canada:

  • The ultimate parent entity must file the GIR
  • No GIR notification needs to be filed.

If a ultimate parent entity or designated filing entity located outside Canada has already filed the GIR directly with the CRA:

  • No each constituent located in Canada is required to file the GIR
  • No GIR notification needs to be filed.

If however, no designated filing entity is appointed and the ultimate parent entity of the MNE group is not located in Canada, and no GIR has been filed by a ultimate parent entity or designated filing entity located outside of Canada:

  • Each constituent entity located in Canada, or an appointed designated local entity must file the GIR
  • No GIR notification needs to be filed

When an MNE group is filing a GIR in a jusrisdiction other than Canada

If a qualifying foreign filing entity (QFFE) is filing the GIR in the jurisdiction where it is located:

  • No constituent entity located in Canada needs to file the GIR
  • The appointed designated notification entity or each constituent entity located in Canada must file a GIR notification

However, if the QFFE has not successfully filed the GIR in the jurisdiction where it is located:

  • An appointed designated notification entity or each constituent entity located in Canada must file the GIR
  • An appointed designated notification entity must file the GIR notification or each constituent entity located in Canada must have previously filed the GIR notification

Who must file a global minimum tax return

Each person who is liable to pay tax under Part 2 or Part 3 of the Act, or each Canadian filing entity, must file a global minimum tax return with the CRA.

Who can file a global minimum tax return on your behalf

If you are filing a global minimum tax return and more than one person in respect of your MNE group is required to file a global minimum tax return for a fiscal year, one of those persons who is resident in Canada may be appointed as a Canadian filing entity.

Qualified Income Inclusion Rule

A qualified Income Inclusion Rule (IIR) for a fiscal year means an IIR that has qualified status (including transitional qualified status) for the fiscal year as determined by the Inclusive Framework and published on the website of the Organisation for Economic Co-operation and Development.

Qualified Undertaxed Profit Rule

A qualified Undertaxed Profit Rule (UTPR), for a fiscal year, means a UTPR that has qualified status (including transitional qualified status) for the fiscal year as determined by the Inclusive Framework and published on the website of the Organisation for Economic Co-operation and Development.

Constituent entity

A constituent entity refers to any entity or permanent establishment that is part of the multinational enterprise (MNE) group subject to the global minimum tax rules.

Low-tax entity

A low-tax entity means a constituent entity of an MNE group that is located in either of:

  • (a) a low-tax jurisdiction
  • (b) a jurisdiction that would be a low-tax jurisdiction, if the effective tax rate of the MNE group for the jurisdiction were determined without regard to any income or expense recorded by an entity in respect of an intragroup financing arrangement.

    (entité à faible imposition)
What is a designated local entity

A designated local entity refers to a Canadian constituent entity within a multinational enterprise (MNE) group that is designated by the other Canadian constituent entities of the group to file the GloBE Information Return (GIR) on their behalf.

What is a designated filing entity

A designated filing entity refers to a constituent entity within a multinational enterprise (MNE) group that has been appointed by the group in substitution for the ultimate parent entity to submit the GloBE Information Return (GIR) on behalf of the group. This entity must meet has both of the following conditions:

  • The entity must have been given everything it may reasonably require to comply with the GIR filing obligations
  • The entity must be located in a jurisdiction that has a qualified Income Inclusion Rule (IIR) or a qualified Undertaxed Profit Rule (UTPR)
What is a designated notification entity

If you are filing a GIR Notification and more than one constituent entity of a qualifying MNE group is required to notify the CRA for a fiscal year for which there is a qualifying foreign filing entity in respect of the MNE group, one of those constituent entities that is located in Canada may be appointed as a designated notification entity.

In such case, the appointed designated notification entity will file the GIR Notification on behalf of all the other Canadian constituent entities.

What is a qualifying foreign filing entity (QFFE)

A qualifying foreign filing entity (QFFE) is an ultimate parent entity or a designated filing entity of the MNE group that is located in a foreign jurisdiction and that is obligated to file a GloBE Information Return with the tax authority of the foreign jurisdiction, provided that the foreign jurisdiction has a qualifying competent authority agreement that is in effect on or before the GloBE Information Return exchange date for the fiscal year. Canada must be a party to that agreement for the entity to be a QFFE.
